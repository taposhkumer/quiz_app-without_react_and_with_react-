# React Quiz App

This quiz app was rebuilt in React while keeping the same structure, styling, and behavior as the original version.

## What is included

- Multiple-choice questions
- One answer selection at a time
- Score tracking
- Final result screen
- Restart button
- Visual styling matching the original design

## Project structure

```bash
.
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   └── index.css
├── README.md
└── .gitignore
```

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

- React
